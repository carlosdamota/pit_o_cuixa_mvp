1🔐 Acceso y login

  • Entra en pitocuixa.es/pitocuixa. Si no tienes sesión, te redirige a la pantalla de Login.
  • Escribe tu usuario y contraseña y pulsa Entrar.
  • Protección anti fuerza bruta: 10 intentos/minuto por IP y 5 intentos cada 5 min por usuario. Si superas el límite, la cuenta se bloquea 15 minutos.
  • La sesión se guarda en la cookie pit_session y dura 8 horas. Pulsa Salir para cerrarla.
  • Con la sesión activa accederás al Dashboard y al menú: Productos, Categorías, Import/Export y Ajustes.
Flujo: Login → contraseña correcta → código 2FA (paso 2) → sesión iniciada

2🛡️ 2FA: verificación en dos pasos

  • Tras la contraseña, el panel pide un código de 6 dígitos generado por tu app autenticadora (Google Authenticator, Authy, Microsoft Authenticator…). El código cambia cada 30 segundos.
  • Se acepta el código con ±30 s de margen por reloj. Máximo 5 intentos: si fallas todos, el desafío se bloquea y debes hacer login de nuevo.
  • Primer alta: el primer login te guía — escanea el código QR con tu app (emisor «Pit o Cuixa») y confirma con un código de 6 dígitos. Desde entonces el 2FA queda activado.
  • El secreto del autenticador se guarda cifrado en la base de datos (AES-256-GCM con la clave TOTP_ENC_KEY del archivo .env).
  • Códigos de respaldo: el sistema genera 10 códigos de un solo uso (10 caracteres cada uno). En la pantalla del código 2FA, pulsa el enlace «Usa un código de respaldo», escribe uno y entra con «Entrar con respaldo». Cada código vale una sola vez; después queda marcado como usado.
⚠ Importante: en esta versión los códigos de respaldo se generan y se guardan cifrados (hash bcrypt) en la base de datos, pero no se muestran en ninguna pantalla. Si pierdes el móvil con la app autenticadora, los códigos actuales no se pueden consultar: solicita una regeneración del alta 2FA (vuelve a hacer login y repite el escaneo del QR), lo que crea 10 códigos nuevos y anula los anteriores. Guarda los códigos en un lugar seguro cuando se faciliten.

3🍗 Productos: crear y editar

  • Crear: botón «+ Nuevo Producto» → se abre un panel lateral con el formulario. Cámbialo a Editar pulsando cualquier fila de la tabla de productos.
Nombre (ES) *Obligatorio. Es el texto base que se traduce al resto de idiomas.
Descripción (ES)Texto descriptivo del producto en español.
Categoría *Desplegable: Menús, Platos principales, Picoteo, Bebidas, Postres, Portes, Otros.
Precio (€)Número con decimales (ej. 12.50).
Imagen / CartelPega una URL o pulsa «📁 Subir Imagen» (JPG, PNG, WebP, GIF, AVIF · máx. 5 MB · se optimiza automáticamente a WebP).
🌐 Traducir auto.Activada por defecto: al guardar, DeepL rellena Inglés, Catalán y Ucraniano.
✓ ActivoMarca si el producto se ve en la web pública.
  • Guardar crea el producto (o aplica los cambios si editas). La web pública se actualiza al instante.
  • Eliminar un producto no lo borra de la base de datos: lo desactiva (deja de verse en la web y puedes reactivarlo editándolo).
  • El sistema garantiza direcciones web (slug) únicas por tipo de producto; si hay colisión, renombra solo.

4⚙️ Ajustes (Settings)

  • Carrusel Visual de la Carta: interruptor para activar/desactivar el visor interactivo de imágenes en la carta pública. Indica cuántas imágenes hay cargadas (se asignan editando cada producto).
  • Datos de la Empresa: Dirección (pie de página público), Teléfono principal y WhatsApp (número del botón flotante de la web; si lo dejas vacío se usa el teléfono principal).
  • Pulsa Guardar para aplicar los cambios.

5🌐 DeepL: traducciones y API key

  • El español (ES) es el idioma fuente. El sistema traduce nombres y descripciones a Catalán, Inglés (EN-US) y Ucraniano.
  • Cuándo traduce: ① casilla «Traducir automáticamente con DeepL» al guardar un producto · ② botón «Traducir campos (DeepL)» del Dashboard, que rellena solo los campos vacíos · ③ script manual scripts/translate.php.
  • Si DeepL falla, el Dashboard muestra el motivo del error; el guardado del producto nunca se pierde por un fallo de traducción.
Cómo conseguir la API key:
  1. Ve a deepl.com/pro-api y crea una cuenta.
  2. Elige el plan Free (gratis, 500.000 caracteres/mes; pide tarjeta solo para verificar) o el plan Pro de pago.
  3. En el panel de tu cuenta, copia la «Clave de autenticación» (las claves Free terminan en :fx).
  4. Edita el archivo .env del servidor y añade: DEEPL_API_KEY=tu-clave.
Sin clave configurada las traducciones quedan desactivadas (el resto del panel funciona con normalidad). Con clave Free, el sistema detecta el servidor de DeepL automáticamente.
